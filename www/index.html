FakaApache Example Site

This example page confirms that FakaApache is serving static files correctly.

You can also configure FakaApache as a small HTTP reverse proxy by setting forward_address and forward_port in siteconfig.fakaapache.

With forwarding enabled, GET requests are sent to the configured upstream application instead of being served from this directory.

See the FakaApache documentation for build and configuration information.
