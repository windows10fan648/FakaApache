Documentation

FakaApache is a small educational C++17 HTTP server for static files and optional HTTP reverse-proxy forwarding.

Run the server

Run it from the project root so the default configuration can find the www directory:

fakaapache.exe --config siteconfig.fakaapache

The default site listens on 127.0.0.1:8080.

Build on Windows

MSVC and CMake are the recommended Windows toolchain:

cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release

The executable is created at build/Release/fakaapache.exe.

HTTP forwarding

Set both values to forward GET requests to another HTTP application:

forward_address = 127.0.0.1
forward_port = 3000

FakaApache opens one upstream connection per request and returns 502 Bad Gateway if the upstream cannot be reached. GET and POST are supported; POST bodies require Content-Length and are limited to 10 MiB. Forwarding is intended for local or trusted services.

Operational boundaries

  • Static mode accepts GET and HEAD; forwarding mode also accepts POST.
  • Request headers are limited to 16 KiB and clients have a five-second receive timeout.
  • Static paths are canonicalized and prevented from escaping the document root.
  • TLS, authentication, rate limiting, compression, and production-grade proxy features are not included.

MinGW-w64: compatibility support is scheduled for removal. Use MSVC and CMake for new Windows builds.
